## The line

> This morning my neighbour left a tomato on my doorstep with a note: 'Yours grew better than mine.'

98 characters — one clean line about a small good thing that happened today.

## Why this line

- **On subject:** a small good thing that happened today, told in the first person.
- **Warmth:** a neighbour's quiet kindness, left on a doorstep before the day began.
- **Surprise:** the note turns a friendly rivalry into a concession — the neighbour admits defeat, graciously, in writing, and the prize is a tomato.
- **Concreteness:** one tomato, one doorstep, one note, this morning — a scene you can picture, not a sentiment.
- **Fresh wording:** no greeting-card phrasing, no borrowed sentiment; the joke is in the neighbour's own words.

## How it works

`main.ts` (Node 22+, stdlib only) writes the line to `/output/entry.txt`. It refuses to write a line outside the 1–200 character gate or with an embedded newline, and it empties only the contents of the output directory, never the directory itself.

```sh
node main.ts            # writes /output/entry.txt
node main.ts /tmp/out   # writes to a directory of your choice
```
